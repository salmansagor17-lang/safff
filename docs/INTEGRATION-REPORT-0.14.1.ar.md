## التغييرات الجديدة

تغيّرت مسارات الصور والأوصاف البديلة والبيانات الوصفية لأسئلة الميكاب الـ500 في Supabase. لم تتغير نصوص الأسئلة أو إجاباتها أو درجاتها في هذه المقارنة. بقي البنك 3286 سؤالًا في 20 تصنيفًا، منها 1050 سؤالًا مصورًا، بثلاث درجات 100 و300 و500.

كانت معالجة الصور مستمرة أثناء المراجعة: بدأت اللقطة بـ301 مسار `makeup-v4` ثم زاد العدد. آخر لقطة اجتازت قراءتين متطابقتين تحتوي **492 مسار makeup-v4 و8 مسارات makeup-obscured**. تم الحفاظ على الثماني صور كما يحددها المصدر؛ لم نختلق لها مسارات جديدة.

زومنت النسخة الكاملة `data/question-bank-v0.9.0.json` والنسخة المصغرة `defaultQuestions.js`، وحدث إصدار التطبيق والتوثيق واختبار الميكاب. أداة `sync-content.cjs` أصبحت تقرأ الجداول مرتين وتقارن المحتوى قبل استبدال الملفات، لمنع حفظ لقطة مختلطة أثناء تحديث جارٍ. تحفظ نسخة رجوع محلية قبل الكتابة.

## تحديثات لاحقة

بعد انتهاء أي تعديل جديد في Supabase:

```powershell
node --use-system-ca scripts/sync-content.cjs
node --test scripts/test-content-store.cjs scripts/test-session-questions.cjs scripts/test-game-flow.cjs scripts/test-setup-flow.cjs scripts/test-topic-expansion.cjs
```

ثم راجع وارفع التغييرات وانتظر اكتمال النشر وشغّل:

```powershell
node --use-system-ca scripts/verify-production.cjs
```

المطابقة لقطة وقت الفحص؛ تعديل Supabase لاحقًا لا يحدّث ملفات GitHub والبنك الاحتياطي تلقائيًا. تبقى صور Storage بحاجة إلى اتصال حتى عند استخدام البنك الاحتياطي.
