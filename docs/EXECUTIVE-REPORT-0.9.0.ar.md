# التقرير التنفيذي — توسعة تحدي العائلة 0.9.0

## النطاق

تحويل الجلسة من سؤال واحد إلى ثلاثة أسئلة لكل مستوى ولكل تصنيف، وفصل الصور إلى أربعة تصنيفات، وإضافة ألغاز الرموز، ومزامنة المحتوى والنسخ الاحتياطية والتوثيق.

## المخرجات

- 15 سؤالًا لكل تصنيف في الجلسة، موزعة على جولتين: 9 ثم 6.
- 11 تصنيفًا نشطًا بدل 7، مع تعطيل التصنيف الصوري المختلط.
- صور الفواكه: 125 سؤالًا؛ صور الحيوانات: 245؛ صور المعالم: 130؛ أعلام الدول: 50.
- فك الرموز: 50 لغزًا جديدًا، مع تلميحات وإجابات وبدائل لبعض الأسماء.
- إجمالي البنك: 2100 سؤال، منها 550 سؤال صور.
- إضافة 50 ملف علم SVG فعليًا؛ بقيت الصور الأصلية الـ500 ومساراتها ومصادرها محفوظة.
- منع تكرار معرف السؤال أثناء الجلسة وتفضيل مواضيع صور مختلفة في المستوى الواحد.
- عرض حجم الجلسة قبل البدء، وثلاث بطاقات لكل مستوى، وتوزيع أعمدة التصنيفات بما يناسب زيادة عددها.
- نسخة أسئلة محلية كاملة ونسخة مصغرة تدعم نفس القاعدة الجديدة.
- ملف منهجية مستقل: `PLATFORM-METHODOLOGY.ar.md`.
- استبعاد ملفات التوثيق والإدارة والنسخ الاحتياطية من الموقع المنشور.

## الخدمات

GitHub يحتفظ بالكود، Vercel ينشر تحديثات `main` تلقائيًا، وSupabase يحتفظ بالأسئلة والتصنيفات. صور البنك القديم في Storage وصور الأعلام ضمن ملفات الموقع. تحديث بيانات Supabase مستقل عن نشر GitHub؛ ليس هناك تنفيذ تلقائي لملفات SQL.

## التحقق

تُسجل نتيجة النشر والتحقق الفعلي بعد تطبيق تحديث المحتوى. الاختبارات الحالية تغطي التحميل الكامل، السحب والجولات، صلاحية المحتوى، وتدفق اللعب بمحاكاة DOM في الأوضاع الثلاثة. المتصفح المرئي غير متاح في جلسة التنفيذ؛ لا ندّعي فحصًا بصريًا للأجهزة.

## الحدود التشغيلية

كل التصنيفات تعني 165 سؤالًا في الجلسة؛ يمكن اختيار عدد أقل. الصعوبة تحريرية وتحتاج تقييم اللاعبين. الصور القديمة تتطلب الوصول إلى Storage عند استخدام البنك المحلي. احتفظنا بنسبة مصادر الصور وترخيص الأعلام.

## التراجع

حُفظت نسخة المحتوى قبل التغيير محليًا خارج المستودع. يوجد SQL للرجوع بعد مراجعة أثره، وتاريخ Git للكود. الرجوع إلى نشر سابق وحده لا يعكس تغييرات المحتوى.
