# تقرير الإصدار 0.15.0

التاريخ: 25 سبتمبر 2026

## تنظيم المشروع

تم حذف ملفات الاستيراد والـJSON التاريخية غير المستخدمة، ونقل الأدوات إلى `scripts/content`, `scripts/tests`, `scripts/ops`, `scripts/maintenance`. أصبحت snapshots المحلية تحت `data/generated`، والوثائق مقسمة إلى `architecture` و`releases`.

## قاعدة البيانات

- الاحتفاظ بـ`game_difficulty_levels` و`game_session_settings` كجداول إعداد منظمة.
- إضافة `question_answers` للإجابات متعددة اللغات.
- إضافة `question_media` للفصل بين صورة السؤال وصورة الإجابة، وحذف جدول الوسائط القديم المكرر `question_media_assets`.
- إضافة `vw_content_overview`.
- إضافة 20 View للتصنيفات مع `security_invoker=true`.
- 740 سجل إجابة منظمة: 370 عربي + 370 إنجليزي.
- 250 سجل Answer Media لتصنيف ديزني.
- Security Advisor: 0 lints.

## الفواكه والحيوانات

- الفواكه: 125/125 إجابة عربية + إنجليزية.
- الحيوانات: 245/245 إجابة عربية + إنجليزية.
- تم تحديث الـfallback المحلي ليطابق هذا الأسلوب.

## ديزني

- 250 سؤالًا بلا صورة في مرحلة السؤال.
- 250 سجل صورة مخصص لمرحلة الإجابة.
- عند الضغط على «إظهار الإجابة» تستخدم الواجهة MediaWiki API للبحث عن صورة الشخصية/الفيلم، ثم fallback لصورة الفيلم عند الحاجة.
- رابط مصدر Wikipedia يظهر تحت الصورة.

## التصميم

تم تحويل الألوان والخطوط إلى Design System مركزي. الخطوط: Alexandria + IBM Plex Sans Arabic. الألوان الجديدة: Coral, Mint, Sky, Plum، موزعة على البطاقات والفرق والمستويات والحالات التفاعلية.

## الاختبارات

يشمل الإصدار اختبارًا صريحًا يثبت أن صورة ديزني لا تظهر قبل كشف الإجابة وتظهر بعدها.
