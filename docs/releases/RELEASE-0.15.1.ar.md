# تقرير الإصدار 0.15.1

## إعدادات الجلسة
- الإعدادات تُقرأ من `game_session_settings` في Supabase.
- عدد الأسئلة من كل مستوى: 1، 2، 3، أو 4.
- عدد الأسئلة من كل تصنيف: 3، 6، 9، أو 12، ويتزامن تلقائيًا مع اختيار عدد الأسئلة من كل مستوى.
- مدة السؤال: بدون وقت، 15، 30، 45، أو 60 ثانية.

## الميكاب
- تبقى صور `makeup-v4` هي المصدر الحي من Supabase Storage.
- أضيفت طبقة إخفاء عرضية خاصة بالميكاب فوق مناطق النص الأكثر شيوعًا.
- الصورة نفسها لا تُفلتر بالكامل؛ تبقى كبيرة وواضحة حتى 1200px / 66dvh.

## التحقق
- اختبارات المشروع تشمل الجلسة الديناميكية، وضع بدون وقت، وطبقة إخفاء الميكاب.
- المشروع يستخدم نفس Supabase URL وPublishable Key الآمن للواجهة.
- `vercel.json` موجود وجاهز للنشر على مشروع Vercel الحالي.
