# هيكل قاعدة البيانات — v0.15.0

## لماذا لم نقسم الأسئلة إلى 20 جدولًا فعليًا؟

إنشاء جدول مستقل لكل تصنيف يكرر نفس الأعمدة والسياسات والفهارس عشرات المرات، ويجعل أي تغيير مستقبلي (مثل إضافة لغة أو نوع وسائط) يحتاج تعديل 20 جدولًا. لذلك الهيكل الحالي يستخدم **جدول أسئلة رئيسيًا واحدًا** مع Views منفصلة لكل تصنيف. النتيجة: تنظيم واضح في Supabase بدون تكرار البيانات.

## الجداول

### `games`
تعريف اللعبة وإعداداتها العامة.

### `game_categories`
تعريف التصنيفات وترتيبها وصورها.

### `game_questions`
مصدر الحقيقة للأسئلة: النص، المستوى 100/300/500، الإجابة المتوافقة قديمًا، الخيارات، ووسائط السؤال.

### `game_difficulty_levels`
تعريف المستويات الثلاثة بشكل منظم: 100 سهل، 300 متوسط، 500 صعب، مع تسميات عربية وإنجليزية.

### `game_session_settings`
إعدادات الجلسة القابلة للتوسع: خيارات المؤقت، السماح بدون وقت، عدد الأسئلة لكل مستوى، والحد الأدنى/الأقصى للتصنيفات.

### `question_answers`
طبقة إجابات منظمة متعددة اللغات:
- `question_id`
- `language_code` (`ar` / `en`)
- `answer_text`
- `is_primary`

حاليًا يحتوي على إجابات الفواكه والحيوانات بالعربية والإنجليزية.

### `question_media`
يفصل الوسائط عن نص السؤال، ويدعم مرحلتين:
- `stage = question`: يظهر قبل الحل.
- `stage = answer`: لا يظهر إلا بعد الضغط على «إظهار الإجابة».

حقول مهمة: `provider`, `media_path`, `external_url`, `lookup_query`, `fallback_query`, `source_url`.

ديزني يستخدم `provider = wikipedia-search` في مرحلة الإجابة فقط.

### `feedback`
تقييمات المستخدمين وتعليقاتهم.

## Views التصنيفات

يوجد View لكل تصنيف، مثل:
- `vw_questions_disney`
- `vw_questions_makeup`
- `vw_questions_fruits`
- `vw_questions_animals`
- `vw_questions_general`
- ...إلخ حتى 20 تصنيفًا.

كل View مبني بـ`security_invoker=true` حتى يحترم RLS على `game_questions`.

`vw_content_overview` يعطي ملخصًا لكل تصنيف: العدد النشط وتوزيع 100/300/500 وعدد الإجابات المختلفة.

## الأمن

- RLS مفعّل على الجداول العامة.
- `question_answers` و`question_media` يسمحان بالقراءة فقط عندما يكون السؤال المرتبط نشطًا.
- الواجهة لا تحتوي على Service Role Key.
- آخر Security Advisor أثناء إصدار 0.15.0: لا توجد Lints أمنية.
