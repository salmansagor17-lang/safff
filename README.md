# تحدي العائلة — v0.8.1 Beta

نسخة تجريبية عامة من لعبة عربية جماعية لفريقين، مصممة للعمل من VS Code محليًا ثم نشر نفس المشروع على Vercel.

## محتوى النسخة
- لعبة واحدة فقط: **تحدي العائلة**.
- 7 تصنيفات.
- 2,000 سؤال في Supabase.
- 6 تصنيفات نصية × 250 سؤالًا = 1,500 سؤال.
- تحدي الصور = 500 سؤال صوري.
- التصنيفات النصية: 50 سؤالًا لكل مستوى 100 / 200 / 300 / 400 / 500.
- تحدي الصور: 100 سؤال لكل مستوى 100 / 200 / 300 / 400 / 500.
- في كل جلسة تختار اللعبة عشوائيًا سؤالًا واحدًا لكل مستوى من كل تصنيف مختار.
- 100 = سهل جدًا، 200 = سهل، 300 = متوسط، 400 = صعب، 500 = صعب جدًا.
- فريقان فقط.
- مؤقت واختياره 15 / 30 / 45 / 60 ثانية.
- خصم النقاط، سرقة السؤال، مؤثرات صوتية، وسؤال مضاعف ×2.
- Feedback مجهول: تقييم وتعليق اختياري فقط.

## الخصوصية
لا توجد حسابات مستخدمين أو تسجيل دخول.
أسماء الفرق والنقاط والتقدم تبقى في ذاكرة الصفحة أثناء الجولة فقط ولا تُرسل إلى Supabase ولا تُحفظ في LocalStorage أو SessionStorage. عند انتهاء الجولة أو إعادة تحميل الصفحة تنتهي بيانات الجلسة.

## Supabase
المشروع مربوط بالـProject URL وPublishable Key فقط في `js/config.js`.
المفتاح Publishable ومخصص للاستخدام في واجهات عامة. لا يوجد Service Role أو Secret Key داخل المشروع.

Supabase يحتفظ بالمحتوى الدائم فقط:
- اللعبة
- التصنيفات
- الأسئلة
- وسائط الأسئلة (500 صورة حاليًا)
- Feedback المجهول

## التشغيل في VS Code
1. فك ضغط المشروع.
2. افتح المجلد في VS Code عبر `File > Open Folder`.
3. ثبّت إضافة **Live Server** إذا لم تكن موجودة.
4. افتح `index.html`.
5. اضغط Right click ثم **Open with Live Server**.

لا تحتاج `npm install` ولا Node.js لتشغيل نسخة الـBeta الحالية.

## النشر
المشروع Static Web App ومهيأ للنشر على Vercel. الخطة المعتمدة لاحقًا:

`VS Code ↔ GitHub → Vercel → رابط عام`

ويبقى Supabase هو مصدر بنك الأسئلة والمحتوى.

## التصميم
الواجهة مبنية بـHTML/CSS/JavaScript بدون خلفيات bitmap منخفضة الدقة، وتستخدم أحجامًا responsive وCSS effects لتبقى حادة على الجوال واللابتوب والتلفزيون ودقة 4K.
